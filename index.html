What it does

Everything a small call needs. Nothing it doesn't.

No dashboard, no invites, no monthly bill. Talk2Me is a deliberately small app that does one thing: put a few phones on the same audio call.

Straight from phone to phone

Audio is direct WebRTC. The public MQTT broker only helps phones find each other and never carries your voice.

Four people, full mesh

Each phone holds one encrypted connection per participant. Join or leave mid-call; every pair renegotiates on its own.

Signals the broker can't read

SDP and ICE payloads are encrypted with AES-GCM using a key derived from the room code with PBKDF2. Media is DTLS-SRTP.

Keeps going when the screen locks

A foreground service with CPU and Wi-Fi wake locks keeps discovery, negotiation, and live audio running with the screen off.

A relay when you need one

Strict NAT or mobile data? Add any TURN provider's URL and credentials in Network settings. No rebuild, no accounts in the app.

Nothing to sign up for

No accounts, analytics, contacts, or call history. The app asks for the microphone and, on Android 13+, permission to show the call notification.

How it works

One code. Up to four phones. That's it.

Signaling is the only thing that needs a third party. It runs over free public MQTT brokers, and every payload is encrypted before it leaves the phone.

Swipe the diagram sideways to see all three phones.

If a direct path is blocked, an optional TURN relay can forward the already-encrypted audio. It never sees the room code or the plaintext.

Start a call

Generate a room code like K7M2-XQ9F. The code is the only secret: no phone numbers, contacts, or accounts.

Share the code

Send it however you like — SMS, a chat app, or across the table. Everyone who enters it joins the same room.

Talk

Up to four phones connect. On the same Wi-Fi, audio starts in a few seconds; other networks may need a relay.

Built for real networks

Connects quickly. Recovers quietly.

Group calls have more ways to go wrong than a 1:1 call, so every pair of phones is negotiated and healed independently.

  • Brokers are rotated deterministically from the room code, so both phones always try the same one first.
  • Presence announcements every 500 ms make discovery feel immediate.
  • Four STUN servers, including port 443, plus TCP candidates for networks that dislike UDP.
  • Per-pair ICE restarts, renegotiate requests, and connect timeouts instead of silent hangs.
  • One deterministic initiator per pair, so group calls never collide mid-offer.
  • The room is capped at four; a fifth phone is told the call is full instead of half-joining.

What it honestly can't do

  • Cross-network calls may need a relay. Same Wi-Fi usually connects directly. Mobile data, CGNAT, and corporate Wi-Fi often cannot — no app can create a route that does not exist. Add a free TURN account under Network settings.
  • There is no ringing. Both people open the app and enter the same code. Talk2Me does not run a push service.
  • No video, contacts, or call history. Audio only, on purpose.
  • Swiping the app from Recents ends the call. Pressing Back or locking the screen does not.
  • OEM battery managers can still interfere. Set Talk2Me to unrestricted and allow autostart on MIUI/HyperOS and similar skins.
